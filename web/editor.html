Entrar al editor

El editor guarda los cambios directamente en el repositorio del sitio. Para entrar hace falta un token de GitHub con permiso de escritura sobre este repositorio: funciona como tu contraseña personal y solo vos lo tenés.

¿Cómo creo el token?
  1. En GitHub, entrá a Settings → Developer settings → Personal access tokens → Fine-grained tokens y elegí Generate new token.
  2. Nombre: «Editor de fichas». Vencimiento: el que prefieras (por ejemplo, un año).
  3. En Repository access, elegí Only select repositories y marcá solo mapa-renacentista.
  4. En Permissions → Repository permissions, poné Contents en Read and write. No hace falta ningún otro permiso.
  5. Generalo, copialo y guardalo en tu gestor de contraseñas: GitHub no lo vuelve a mostrar.
